# Netlify Yayini

Bu proje statik HTML/CSS/JavaScript sitesidir; derleme veya paket kurulumu gerekmez. Netlify ayarlari `netlify.toml` dosyasinda tanimlidir.

## GitHub ile otomatik yayin

1. Proje klasorunu bir GitHub deposuna yukleyin.
2. Netlify'da **Add new site > Import an existing project** seceneginden depoyu baglayin.
3. Build komutunu bos birakin; yayin dizini `.` olsun.
4. **Deploy site** secenegine basin. Depoya sonraki push islemleri otomatik yayinlanir.

## Manuel yayin

Netlify'da manuel deploy ekranini acip `index.html`, `css`, `js`, `img` ve `webfonts` ogelerini iceren bu proje klasorunu yukleyin. `netlify.toml` bulunan proje kok dizinini yukleyin.

Yayin sonrasi masaustu ve telefonda menu, WhatsApp siparisi, rezervasyon, iletisim ve harita baglantilarini deneyin. Yayindan once telefon/WhatsApp numarasini, adresi, acilis saatlerini, urun bilgilerini ve musteri yorumlarinin izinli ve gercek oldugunu isletmeyle dogrulayin. Menu fiyatlari sayfada henuz tanimli degildir; siparis akisi guncel fiyat ve teslimat bilgisini WhatsApp'ta sorar.
